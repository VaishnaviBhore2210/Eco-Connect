# EcoConnect - Project Overview

## Introduction

EcoConnect is a full-stack web platform designed to connect urban organic-waste generators with rural women's cooperatives that can collect and process organic waste.

## Problem

Urban areas generate a large amount of organic waste from households, restaurants, offices and other sources. At the same time, rural women's cooperatives can use organic waste for processing into useful products such as compost or biofuel.

The main problem is connecting the waste generators with suitable cooperatives in an efficient way.

## Proposed Solution

EcoConnect provides a platform where:

1. Urban users can list their organic waste.
2. Cooperatives can view available waste.
3. The system can recommend suitable cooperatives.
4. Cooperatives can accept waste and schedule pickups.
5. Pickup status can be tracked.
6. The system can display environmental and economic impact.

## Main Users

### Urban Waste Generator
- Register and login
- Create waste listings
- Enter waste type and quantity
- Provide pickup location
- View pickup status
- View impact

### Cooperative Coordinator
- Register cooperative
- Set processing capacity
- View available waste
- Accept waste
- Manage pickups
- View cooperative information

### Admin
- Manage users
- Manage cooperatives
- Monitor waste listings
- Monitor pickups
- View overall platform activity

## Technology Stack

- Frontend: React.js
- Backend: Java Spring Boot
- Database: MySQL
- API: REST API
- Version Control: Git and GitHub
