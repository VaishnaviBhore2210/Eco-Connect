# EcoConnect 🌱

EcoConnect is a full-stack web platform that connects urban organic-waste generators with rural women's cooperatives that can collect and process organic waste.

## Problem

Urban households, restaurants and offices generate organic waste every day. At the same time, rural women's cooperatives can process organic waste into useful products such as compost or biofuel.

EcoConnect aims to provide a digital platform that connects these two sides.

↓
Waste Processed
↓

## Main Users

### Urban Waste Generator
- Register and login
- Create waste listings
- Enter waste type and quantity
- Provide pickup location
- Track pickup status
- View environmental impact

### Cooperative Coordinator
- Register cooperative
- Set processing capacity
- View available waste
- Accept waste
- Manage pickups
- View cooperative information

### Admin
- Manage users
- Manage cooperatives
- Monitor waste listings
- Monitor pickups
- View platform activity
